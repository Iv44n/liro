# Liro web

Liro dashboard (TanStack Start + shadcn/base-ui). Scaffolded from `rh/web`: authentication and organizations (members, invitations, settings).

```bash
bun run dev    # http://localhost:3003 (needs the API at VITE_API_URL, default http://localhost:3002)
bun run build
bun run test   # vitest
bun run lint
```
